Project 15: Electric Vehicle (EV) Adoption Trends – Time-Series
Forecasting

Dataset: EV Sales Dataset (Kaggle)
Introduction:
EV adoption is accelerating globally. This project forecasts future sales and analyzes adoption
drivers (policy, fuel prices).

Key Questions to Answer:
1. Which countries lead in EV adoption?
2. How do government incentives impact sales?
3. Can we predict 2030 EV sales using historical data?
4. State how (3) is possible
   
Tasks to Perform:
● Merge EV sales with fuel price datasets.
● Forecast sales using Prophet/XGBoost.

Deliverables:
● EV adoption forecast model.
● Policy recommendation report.
